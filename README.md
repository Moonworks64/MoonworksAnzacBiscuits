This is a mod for Cookie Clicker which adds extra minigames to the buildings.
Currently it adds:<br>
    - Incubator Vats (for You).<br>

(I'm working on adding more okay!)<br>

Load the mod by putting:<br>
Game.LoadMod('https://moonworks64.github.io/MoreCookieMinigames/MoreMinigames.js');<br>
into the console, which can be accessed by right-clicking -> inspect -> console.<br>

No Steam version yet! I don't have Cookie Clicker on steam, sorry!
